02What the plugin does

omadocs uploads a new copy of a local DOCX, XLSX, or PPTX file to the Google Drive account you select and opens the link returned by Google in your default browser.

  • Each new upload creates a separate Drive copy, including repeat uploads of the same local file.
  • The plugin does not synchronize files. Edits in Google do not update the local original.
  • Reopening an existing upload uses its stored Google link without uploading another copy.
  • Cancelling an upload cannot undo a file Google has already received.
  • Account removal and uninstallation do not delete uploaded Drive files.
