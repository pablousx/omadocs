# Interface previews

Native panel captures for version 0.1.2, using fictional accounts and documents in a temporary preview loaded into the existing shell. No Google requests or real account data were used. The preview was removed after review.

The panel uses a theme-scaled width of 380 pixels. Heights fit the current display, capped at a theme-scaled 650 pixels. Recorded image dimensions depend on the capture session's display scale.

- `accounts.png`: account list and primary actions.
- `uploads.png`: completed uploads and browser links.
- `progress.png`: authentication recovery and account-choice states.
- `settings.png`: settings navigation.
- `alert.png`: authentication recovery state retained as the alert-focused preview.

The header icon uses the theme foreground color. Section labels, separators, and actions follow the compact native panel hierarchy. These images document the release appearance.
