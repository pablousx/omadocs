# Interface previews

Native panel captures for version 0.1.1, using fictional accounts and documents in a temporary preview loaded into the existing shell. No Google requests or real account data were used. The preview was removed after review.

The panel uses a theme-scaled width of 440 pixels (513 pixels with the capture session’s font scaling). Heights fit the current display, capped at a theme-scaled 650 pixels.

- `accounts.png`: account list and primary actions.
- `uploads.png`: completed uploads and browser links.
- `progress.png`: upload progress and browser failure feedback.
- `settings.png`: settings navigation.
- `alert.png`: dismissible authentication alert.

The header icon uses the theme foreground color. These images document the release appearance.
